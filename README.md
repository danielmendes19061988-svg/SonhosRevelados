# Sonhos Revelados

Aplicativo Flutter Android para registro e reflexão sobre sonhos.

## Status
Reconstrução V1 em andamento. A branch `rebuild/flutter-v1` contém a nova base compilável do app.

## Desenvolvimento
1. Instale Flutter estável e Android SDK.
2. Execute `flutter pub get`.
3. Execute `flutter test`.
4. Execute `flutter build appbundle --release`.

## Publicação
O projeto será preparado para Google Play com target Android 16 / API 36, AAB, política de privacidade e materiais da ficha da loja.

Interpretações no aplicativo são apresentadas como conteúdo simbólico/reflexivo, não como previsão ou aconselhamento profissional.
